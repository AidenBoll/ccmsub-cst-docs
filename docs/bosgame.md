# Bosgame Box + Dell AIO

To use the Dell AIO's as an external monitor, you need to install the
"**Dell On-Screen Display Application**" on the Windows side.

[OptiPlex 7470 AIO Driver Downloads](https://www.dell.com/support/product-details/en-us/product/optiplex-7470-aio/drivers)

Make sure the mini PC is plugged into the Dell's **HDMI IN** port
(the one with the little symbol next to it).

Hit the tiny, hidden button on the underside of the AIO (near the power button)
to switch the input between the internal PC and the HDMI connection.
